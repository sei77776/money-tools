# お金の制度計算ツール（2026年対応）

2026年（令和8年）の制度変更に対応した無料計算ツール集。

**公開サイト**: https://sei77776.github.io/money-tools/

## ツール

- **ふるさと納税シミュレーター＋寄付管理** — 控除上限額の目安計算、寄付記録（localStorage）、ワンストップ特例の期限カウントダウン・ICSカレンダー出力
- **年収の壁・手取りシミュレーター** — 130万・178万円の壁と2026年10月からの社会保険新ルール（週20時間）の判定、手取りカーブの可視化

## 技術構成

- 静的サイト（Vanilla ES Modules・ビルド不要・ランタイム依存ゼロ）
- 計算ロジックは `public/lib/` の純関数。制度数値は `public/lib/params2026.js` に出典付きで一元管理
- テスト: Vitest（ユニット）＋ Playwright（スモーク）

```bash
npm install
npm test              # ユニットテスト
npm run serve         # http://127.0.0.1:8931
node tests/e2e-check.mjs  # サーバ起動状態で実行
```
