# ソーシャルメディア部門 (Social Media)

## 役割

各プラットフォームの作法に合わせた発信。投稿の執筆、フック、フォーマット、
プロフィール最適化、Reels 台本、YouTube サムネイル、ネタ出し、
そして「その人の声」の再現。

## 声（Voice）が前提

この部門のスキルは、プロジェクト直下の `about-me.md` と `voice.md` を参照する。
**この 2 ファイルが無い状態で投稿を書かない。** 無ければ先に
`voice-builder` を実行する（インタビュー + 文章サンプル 3〜5 本から生成）。

声のファイルが無いまま書いた投稿は、一般的にうまいが本人らしくない文章になり、
結局全部書き直しになる。

## 優先スキル

| 場面 | スキル |
|------|--------|
| 声の初期構築（**最初に実行**） | `voice-builder` |
| ニュースレターの声 | `newsletter-voice` |
| 投稿を書く（本人の声で） | `post-writer` |
| フレームワーク適用（PAS / AIDA / BAB / STAR） | `post-formatter` |
| 書いた投稿の採点・改善 | `post-scorer` |
| 冒頭のフックを複数案 | `hook-generator` |
| ネタが無い / 月間の計画 | `content-matrix` |
| Instagram Reels の台本 | `reels-scripting` |
| YouTube サムネイル | `youtube-thumbnail` |
| プロフィール改善 | `profile-optimizer` |

## プラットフォーム別のリライト

同じ素材を複数プラットフォームに出すときは、**要約ではなくリライトする**。

| | 構造 | 長さの目安 | 注意 |
|---|------|-----------|------|
| **X** | 1 ツイート完結 or スレッド。1 行目で完結する主張 | 短い | 外部リンクは伸びにくい。リプライに置く |
| **LinkedIn** | 3 行フック → 空行区切り → 1 行 1 文 | 200〜250 語 / 20 行以内 | モバイル前提。「続きを読む」の前で止めない |
| **Instagram** | ビジュアル起点。キャプションは補助 | 短め | 画像・Reels が主、文は従 |
| **YouTube** | サムネ → タイトル → 冒頭 15 秒 | — | サムネを先に作る（`youtube-thumbnail`） |

## 他部門との連携

- **← Marketing**: ブログ・LP・ローンチの素材を受け取り、各プラットフォーム用に変換する。
- **← Designers**: サムネ・カルーセル・OGP は `brand` のブランド定義に従う。
  画像制作は `banner-design` に回す。
- **→ Legal**: 実績・数値・顧客名・比較を出す投稿は、公開前に確認する。
  顧客名の掲載には許諾が要る。

## この部門の譲れない一線

1. **`voice.md` 無しで本人名義の投稿を書かない。**
2. **公開は必ず人間が行う。** Claude は下書きまで。
3. **数値実績は裏取りしてから出す。** 一度出した数字は消しても残る。
4. **プラットフォーム間で使い回さない。** 毎回書き直す。
